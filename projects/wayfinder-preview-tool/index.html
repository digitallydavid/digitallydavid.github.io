Wayfinder Preview Tool

An in-editor character and cosmetics preview pipeline built to get clean, consistent renders without ever opening the full game level.

Project Overview

Wayfinder shipped with dozens of playable characters and a constantly growing wardrobe of cosmetics, each with their own dye variants. Getting a clean, consistent shot of any of them (for marketing, for the in-game store, or just to sanity-check how a piece looked on a character it wasn't originally designed for) meant loading the full game level, finding the character, and fighting lighting and camera setup every single time.

I built the Preview Tool to cut all of that out. It's an Editor Utility Widget backed by a C++ core that spins up a dedicated, pre-lit preview scene, loads any character with any equipment combination and dye swatch applied, and drives the pose through a Sequencer track, all from a single panel inside the editor.

Technical Implementation

Multi-Mesh Equipment Loading

Characters in Wayfinder aren't a single skeletal mesh: a fully-equipped character can be stacked out of several meshes across body, armor, and weapon slots. Early versions of the tool only handled one mesh at a time; I rebuilt the loading path to resolve and attach an arbitrary number of skeletal meshes per character so a full loadout previews correctly in one pass.

Dye Swatches & Duplication

Cosmetics support dye variants, so the tool reads from a dye swatch table to preview any color variant on demand instead of needing a separate asset per dye. I later added duplication support so an artist could clone an existing preview setup (camera, pose, and lighting included) as a starting point for a new character or cosmetic, rather than rebuilding the scene from scratch each time.

Pose & Sequence Driven Renders

The preview scene is driven by a Sequencer track, so poses and camera moves are reusable and consistent across every character run through the tool, which is what makes the output usable as store and marketing imagery rather than just an editor screenshot.
