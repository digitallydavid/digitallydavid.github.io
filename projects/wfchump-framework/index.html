WFChump: Ambient NPC Framework

The data-driven personality system behind Wayfinder's ambient NPCs, plus the in-editor tool built to stage and preview them.

Project Overview

WFChump started as a small prototype: a base class for ambient, non-quest NPCs with just enough logic to stand around and look alive. I took that scaffold and built it out into the framework actually used across dozens of named NPCs in the game: reading "personality" data from soft-referenced data tables so each NPC's fidgets, greeting animations, and dialogue hookups are authored as data rather than one-off Blueprint logic per character.

Because the system is data-driven, adding a new ambient NPC personality is a data table entry and an animation set, not a new code path. On top of the runtime framework, I also built a dedicated in-editor tool, the NPC Drafter, that lets us stage and pose an NPC in an isolated preview scene without loading the full game level, which made iterating on new personalities and fidget sets dramatically faster.

Technical Implementation

Data-Driven Personalities

Each NPC's behavior is described by an entry in a personality data table, which the base Chump class reads to decide which fidget montages to play, how to greet the player, and which dialogue hooks to fire. Later passes added montage fade in/out driven straight from the same table, so personality polish didn't require touching code.

NPC Drafter Tool

Previewing an NPC used to mean loading it into a real level. I built a custom Unreal Editor tool (its own asset editor, viewport, and Slate-based widget UI) that stages an NPC on a dedicated preview actor using the engine's preview scene, so writers and animators could iterate on a personality in isolation. That included a small modification to the engine's own preview scene class to support the staging workflow the tool needed.

Scope Note

The base Chump class was originally scaffolded by a teammate as a simple puppet system. Nearly everything the shipped framework actually does (the personality data-table system, fidget/greeting/dialogue hookups, and the NPC Drafter tool) was built on top of that starting point across about a year of iteration.
